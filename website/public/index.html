Read what your agents write.

Galley is a calm reader for the Markdown your AI agents write. Every file reads like a typeset page. What an agent changed after you read it is marked in the margin. What you have to say goes back as feedback.

Point it at a folder

Open the folder your agents write into, and Galley lists its Markdown files, watches them, and shows new ones the moment they appear. Keep as many folders as you have projects; each sits in the rail with an icon and colour of its own. A single file opens too, straight from Finder.

Then read. Scroll to the end of a page and keep pulling: the next file slides in. Galley remembers where you stopped in every file, and which ones you have read.

See what changed

Agents rewrite files while you are away. Galley keeps a copy of each file as you last read it, and when you come back it shows what is new — in the page itself, not in a diff.

A paragraph the agent added carries a bar in the margin and a wash, like this one. In a paragraph it only edited, the words that came in are marked.

Removals stay out of your way. New files get a blue dot and changed ones an amber one, in the file list, on the workspace and on the Dock icon. ⌘J jumps to the next change.

Mark it up, hand it back

Reading a plan, you will disagree with something. Select it and highlight it, or add a note to say what you want — the way you would mark up a printout.

Like this: a note sits under the passage it is about.

Your marks are purple, so they never look like the agent's changes. When you are done, Copy File Feedback puts every passage and note on the clipboard, with the file and section each one is in, ready to paste to the agent.

Or let the agent read it

Install the galley command and its skill — one click each, from the app — and tell your agent to address my feedback in Galley. It reads what you marked, makes the changes, and clears what it finished.

$ galley feedback plans/auth.md
## /Users/you/project/plans/auth.md

1. Marked in Rollout › Token shape:
   > Tokens live for 15 minutes.

   Make it 10 for admin sessions.

$ galley feedback clear plans/auth.md
Cleared 1 highlight on 1 file.

The skill works with Claude Code, Codex, Cursor and other agents that read skills. Passages an agent rewrote drop out of the feedback by themselves.

Find anything

One palette, four ways in. ⌘K goes to a file by name; type # for a section of the page you are on, or > for anything Galley can do. ⇧⌘F searches the text of every file, and ⇥ switches between names and text.

Make it yours

Nineteen themes, light and dark — Galley's own Paper, Sepia, Graphite and Ink, and Solarized, Nord, Dracula, Rosé Pine, Catppuccin, Tokyo Night, Gruvbox and GitHub. Six typefaces, and the size, spacing and width of the text. The Dock icon comes in ten colours.

Paper, not an editor

  • Read-only. Galley never writes to a Markdown file.
  • Nothing leaves your Mac. No account, no analytics, no network. Your highlights and notes stay in Galley.
  • Safe to open. Scripts, styles and frames in a file's HTML are removed before the page is drawn, and a link never starts an app or a script — it shows it in Finder.
  • The Markdown agents write. Tables, task lists, code, maths, Mermaid diagrams, callouts, footnotes, front matter.
  • Native. Built for the Mac in Swift, with the keyboard and trackpad in mind.
