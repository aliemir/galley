Help with Galley

Galley comes with a guide: choose Help → Galley Guide in the app. For anything it does not answer, open an issue on GitHub — bugs, questions and ideas are all welcome there.

Where are my highlights and notes?

On your Mac, in ~/Library/Application Support/Galley. Galley never writes them into your Markdown files.

How does an agent read my feedback?

Open Settings → Agents (or the terminal button at the top right of a page) and install the galley command and the agent skill. Then ask your agent to address your feedback in Galley. You can also copy it with Copy File Feedback (⇧⌘C) and paste it in.

A file looks different from GitHub

Galley removes scripts, styles and frames from the HTML in a Markdown file before showing it, and keeps only the tags that cannot change how the page behaves. If something you expect to see is missing, please open an issue with the file.

How do I remove Galley completely?

  • Quit Galley and move it to the Trash.
  • Delete ~/Library/Application Support/Galley (your library) and, if you like, its settings: defaults delete com.aliemir.galley in Terminal.
  • If you installed them, remove the command and the skill first, from Settings → Agents.
