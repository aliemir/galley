Privacy

Last updated November 2, 2026

Galley collects nothing about you. This page says exactly what it does with the things it does handle.

The app

  • No account, no analytics, no tracking. Galley has no sign-in, sends no usage data and contains no third-party analytics or advertising code.
  • One request: updates, if you allow it. Galley asks before it checks for updates. If you agree, it fetches the list of releases from GitHub about once a day — the request carries Galley's version and, like any request, your IP address; nothing about you or your files. Turn it off in Settings → General, or check by hand with Galley → Check for Updates…. Galley makes no other requests.
  • Your files never reach the network. The page Galley draws your files on cannot make a request: remote images in a file are shown as links, not loaded. A link you click opens in your browser.
  • Your files stay where they are. Galley reads the folders and files you open and never writes to them.
  • What Galley keeps, it keeps on your Mac. Your workspaces, read positions, highlights, notes and a copy of each file as you last read it (to show what changed) live in ~/Library/Application Support/Galley; your settings in Galley's preferences. Nothing is synced or uploaded. Deleting that folder removes it all.
  • The galley command reads the same folder, on your Mac, when you or an agent run it. What an agent does with your feedback is up to the agent and its provider.

This website

This site has no cookies, no analytics and no forms. It is served by Cloudflare, which processes requests — including IP addresses — to deliver the pages and protect them from abuse, under Cloudflare's privacy policy.

Downloads and issues

Galley is downloaded from GitHub, and questions and bug reports go to GitHub Issues. GitHub handles both under GitHub's privacy statement; anything you write in an issue is public.

Changes

If this ever changes, this page will say so first, with a new date at the top.
