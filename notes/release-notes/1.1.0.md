Feedback in rounds, changes one at a time, and updates that install themselves.

## Save feedback when it is ready
- Highlights and notes start as drafts — dashed on the page — and only you see them. **Save Feedback** (⌘S, or the button at the top right) saves every draft in the workspace at once, and now your agents see them.
- Editing a saved note makes it a draft again. Prefer agents to see each mark as you make it? Turn drafts off in Settings → General.
- Feedback you left in 1.0 counts as saved.

## Agents can wait for it
- `galley feedback --wait` waits for your next save and prints what it added; `galley feedback --watch` prints every save as it happens. Ask your agent to *keep watching for my feedback*, and it picks up each round as you save it.
- `galley feedback` shows saved feedback only (`--drafts` adds the rest), and `galley feedback clear` leaves your drafts alone.
- Update the agent skill in Settings → Agents so your agents know all this.

## Read changes one at a time
- A tick beside each change marks just that one read — hover it and it says so — or press ⌥⌘J for the change at the top of the page. The last tick marks the file read.
- A file you are ticking through is no longer marked read just by leaving it.

## Updates
- Galley → Check for Updates…, and, if you allow it, a check once a day. It is the one request Galley makes, and it sends nothing about you or your files.

Requires macOS 15 Sequoia or later. Signed with a Developer ID and notarized by Apple. Galley 1.0 does not update itself: download this one from the website once, and from here on updates arrive in the app.
