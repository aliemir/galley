Save Feedback names the agent that is waiting, and file titles and search results read cleaner.

- **Save Feedback names the waiting agent.** While an agent waits on your feedback, the button reads **Send to Claude Code** (or the agent it is, **Send to Agent** when it cannot tell) beside the green dot, instead of leaving the name to a slow tooltip.
- **File titles ignore headings inside code.** A code block only ends at a fence that matches the one that opened it, so a `#` line inside a code block that quotes another code block no longer becomes the file's title.
- **File titles drop closing hashes.** A heading written `# Plan #` is titled "Plan"; hashes that are part of the text, like `C#`, stay.
- **Search results drop nested Markdown prefixes.** A match inside a quoted list or a task list shows its text, not the `>`, `-` or `[ ]` before it.
