Wide tables fit the page, and bare URLs are links.

- **Tables fit the page.** A table full of file paths, code or long links no longer pushes the page sideways: headers wrap, code and links break where they must, and a table that is still too wide breaks its words too, with hyphens. It fits again as you resize the window.
- **Bare URLs are links.** `https://…`, `http://…` and `www.…` written as plain text can be clicked, as on GitHub. Punctuation after a URL stays out of the link; code is left alone.
- **`galley skill install` installs into the current project.** Add `--global` to install it for every project, as the command did before. The app's **Install Globally** button is unchanged.
- **Mark as Unread stays unread** on a page whose end is on screen; before, leaving the page marked it read again.
- A panel swipe that starts at the top or end of a page no longer leaves the page without its bounce.
- Closing the find bar right after turning a page no longer highlights the matches on the new page.
- `galley feedback --wait` and `--watch` no longer miss a save made just as they start.

Requires macOS 15 Sequoia or later. Signed with a Developer ID and notarized by Apple. From Galley 1.1, choose Galley → Check for Updates….
