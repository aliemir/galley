The first release of Galley, a calm Mac reader for the Markdown your AI agents write.

## Read
- Point Galley at the folders your agents write into; it lists their Markdown files, watches them, and shows new ones as they appear.
- Every file reads like a typeset page: six typefaces, nineteen light and dark themes, tables, code, maths, Mermaid diagrams, callouts and footnotes.
- Pull past the end of a page for the next file. Galley remembers where you stopped in every file, and which ones you have read.
- Workspaces, files and contents come and go with a two-finger swipe; files open in tabs.

## See what changed
- What an agent changed since you last read a file is marked in the page itself — a bar in the margin, new words washed — not in a diff.
- New and changed files carry dots in the file list, on the workspace and on the Dock icon. ⌘J jumps to the next change.

## Hand feedback back
- Highlight a passage and add a note; your marks are purple, so they never look like the agent's changes.
- Copy File Feedback (⇧⌘C) puts every passage and note on the clipboard with its file and section, ready to paste to an agent.
- Or let the agent read it: install the `galley` command and its agent skill from Settings → Agents, then ask your agent to address your feedback in Galley.

## Find anything
- ⌘K goes to a file by name — type `#` for a section of the page, or `>` for any action (⇧⌘P). ⇧⌘F searches the text of every file.
- Every shortcut can be changed in Settings.

## Safe to open
- Galley never writes to a Markdown file and sends nothing anywhere: no account, no analytics, no network.
- Scripts and styles in a file's HTML are removed before the page is drawn, and a link never starts an app or a script.

Requires macOS 15 Sequoia or later. Signed with a Developer ID and notarized by Apple.
